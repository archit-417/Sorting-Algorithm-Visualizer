An interactive Sorting Algorithm Visualizer that demonstrates the working of various sorting techniques in real time. Designed to help students and developers understand sorting algorithms through visual representation.

🔹 Features:
✅ Supports popular algorithms: Bubble Sort, Merge Sort, Quick Sort, etc.
✅ Step-by-step visualization for better understanding
✅ Adjustable speed and array size for custom experimentation
✅ Clean and interactive UI for an engaging experience
